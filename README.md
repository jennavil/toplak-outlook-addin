# Toplak Bau Outlook Add-in

Outlook-Add-in für:
- Rechnung
- Offerte
- Zahlungserinnerung
- 1., 2., 3. und letzte Mahnung

## GitHub Pages aktivieren
Unter **Settings → Pages**:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Danach läuft das Add-in unter:
https://jennavil.github.io/toplak-outlook-addin/taskpane.html

## Outlook installieren
Die Datei **manifest.xml** als benutzerdefiniertes Outlook-Add-in installieren.

Das Add-in setzt Betreff und Nachrichtentext in einer bereits geöffneten neuen E-Mail.
Vor dem Versand bitte Empfänger, PDF-Anhang und Absender **buchhaltung@toplak-bau.ch** kontrollieren.
